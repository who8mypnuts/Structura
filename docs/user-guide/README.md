# Structura user guide

Structura builds 3D structures from short grammar scripts (EisenScript), renders them, and exports them.
It is the successor of Structure Synth: every Structure Synth 1.5 script builds the same structure in
Structura.

| [Rendering](rendering.md) | The viewport, the Render view, presets, materials and lights, denoising, saving, render reports, the queue |
