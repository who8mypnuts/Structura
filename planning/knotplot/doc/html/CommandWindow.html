KnotPlot Command Window

Of course this window can be made larger so that it's easier to see what's in it. It is also possible to work without the Command Window by running KnotPlot with the -nomonitor command line option. All KnotPlot output will then go to the terminal window you started KnotPlot from. In this case it is necessary to keep the mouse cursor over one of the KnotPlot windows when typing commands, even though the output appears in another window.
