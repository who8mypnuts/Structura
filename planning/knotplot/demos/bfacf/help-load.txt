BFACF Load Help

Click on one of the buttons to load the indicated knot type into the BFACF engine,
or click the `cancel' button to return to the BFACF Basic control panel.

IMPORTANT NOTE on writhe convention:

   --- The knots in the first section use the TopoII convention for writhe,
       that is the writhe of a minimal crossing diagram is non-negative.  
       If a knot has a `_' in the file name, then it is in the TopoII convention.
       
   --- The buttons in the second section will load a minimal stick candidate 
       from the KnotPlot minimal stick catalog.  In some cases, these knots are
       the opposite chirality from the corresponding TopoII knot.  See below.
       If a knot has a `.' in the file name, then it is in the KnotPlot convention.
       The `1 comp' and `2 comp' buttons randomly select a one or two component
       link and load it into the BFACF engine.

Look in the KnotPlot Command Window when the knot is loaded to see which 
convention it follows.
