This is the source code to the homfly program by Bob Jenkins.
KnotPlot calls this auxilary program in computing the HOMFLY 
polynomial.  The code is in the public domain.

See Bob's web site at: http://burtleburtle.net/bob/
and his HOMFLY polynomial site at: http://burtleburtle.net/bob/knot/homfly.html

In order to make this work with KnotPlot, a few modifications had to be made.
These are indicated with an `RGS mod' comment.
