Exporting Models

This table tells you which command to use to export models to other software, depending on what type of surface (3D, 4D, etc.) and what type of data model (DXF, SDL, etc.).

Surface Type
3D Knot4D Knot
Model Type Polygonal DXF pfdxf spface
B-spline DXF dxf spdxf
Polygonal SDL psdl
B-Spline SDL sdl spsdl
Optik polygons poptik
Optik bézier patches optik
Wavefront polygons wavefront
Dragon b-spline dragon
