Graphs in KnotPlot

Graphs are implemented via the method of bead identification using the identify command.

Creating graphs

The file 3jun96 contains a simple example of using KnotPlot commands to create a linked handcuff graph. To see this example, simply load the script into KnotPlot: 
  KnotPlot> <3jun96
with the < command.
