KnotPlot Command Line Options

-stdin
Reads input from the standard input instead of the keyboard. Useful for demo-scripts.
-nopanel
Will start the program up without the control panel.
-nomonitor
Will start the program up without the command window.
-par parameter value
Sets parameter to value. Example: -par cyl 0.9 sets cyl-rad to 0.9.
-screensaver
Starts up KnotPlot as a screensaver.
-font thefont
Changes the font used in the control panel. For example -font AvantGarde-Book can be nice. Click here to see what fonts are available.
-nographics
Starts KnotPlot up in the shell without any windows. Often useful for generating Postscript figures or running KnotPlot in a batch job.
-beads
Usually KnotPlot starts up in the 'Smooth Tubes' mode. This flag will start it in the 'Beads and Sticks' mode.
-flowers
All I can say, on a decent SGI machine, try it.
-manual
Starts up a WWW browser looking at the KnotPlot Manual (local copy). KnotPlot then exits.
-info
Starts up a WWW browser looking at the KnotPlot Site. KnotPlot then exits.
