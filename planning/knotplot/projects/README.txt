
If you work on several different projects using KnotPlot, it's a good 
idea to keep the files needed for each project in a folder separate
from all the other projects, thereby avoiding icon clutter.  This is easy 
to achieve using shortcuts.  In each of the subfolders you will find 
a KnotPlot icon which is actually a shortcut to the KnotPlot program 
located in the KnotPlot home folder.  However, the properties of each
of the shortcuts so that KnotPlot will startup in the folder where the 
shortcut is located.  Any files created by KnotPlot will be placed in
this "Start In:" folder.

To see how the shortcut is specified, right click on it, and select 
"Properties", you should see the folder path in the "Start In:" field.

You can use the "simple" folder to create new projects easily.  Instructions
are in the README file in that folder.
