
This example project shows how to customize the DemoA panel for use in a specific project.

You can edit DemoA.kps and DemoB.kps with any text editor (for example
Notepad or WordPad).  To open one of the .kps files, right click on 
the icon and select "Open With".  The choose the text editor from the
list of applications presented.


NOTE: This project requires additional data.  Read the instructions in the Data.html file.
