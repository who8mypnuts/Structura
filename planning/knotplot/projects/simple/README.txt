
A simple example of a project.

Double click on the KnotPlot shortcut and KnotPlot will
start up with this folder as the active directory.  Any 
files saved by KnotPlot will be saved to this folder.

To see how the shortcut is specified, right click on it,
and select "Properties".  You can edit the "Start in:" field
to specify a different folder. 

You can use this project to create new projects, just make a 
copy of the "simple" folder and rename the copy or move it someplace
else.  Then edit the shortcut's properties inside your new 
folder to "Start In:" the new folder's location.
